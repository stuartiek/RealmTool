Citizens 2 Documentation

Master the art of NPC creation in Minecraft.

What is Citizens?

Citizens is the premier NPC plugin for Minecraft servers. It allows you to create entities that look like players or mobs, which can talk, trade, guard, and walk paths.

The Official Citizens 2 Engine

Installation

  1. Download Citizens2.jar from the official Dev Builds.
  2. Ensure you have Vault installed if you want economy features.
  3. Place the jar in your /plugins folder.
  4. Restart your server.

Note Always check your server version. Citizens is highly version-specific.

Essential Commands

To edit an NPC, you must first select it by right-clicking it or using the ID.

/npc create <Name> --type <MobType>
/npc select [ID]
/npc rename <NewName>
/npc remove
Visualizing the /npc create command in-game.
Command Result
/npc lookclose NPC head follows players who walk by.
/npc move Teleports the selected NPC to you.

Skin Management

You can give your NPC any player's skin or even a skin from a URL.

Using a Player Name:

/npc skin Notch

Using a Direct Image URL:

/npc skin --url http://i.imgur.com/example.png
Change skins instantly to match your server theme.

Traits (The Logic)

Traits give NPCs special powers. Here are the most popular ones:

  • Text: Use /npc text to add dialogue.
  • Equip: Use /npc equip to give them weapons and armor.
  • Command: /npc command add spawn makes the NPC run a command when clicked.
An NPC equipped with Diamond Armor using /npc equip.
